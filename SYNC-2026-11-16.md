# Sync from live site — 2026-11-16

Picks up the work done on the live site on **2026-11-13**: the four inner
pages, their styling, the contact form, and a few fixes to Home, the header and
the footer. Nothing was written to WordPress during this sync.

## How it was verified

- **Last-modified times** were read from the site. Every page and template
  last changed on 2026-11-13, at the time of one of that day's recorded edits.
  Nothing has changed since.
- **Home (27)** and **Additional CSS** were exported straight from the live
  site. The CSS file's sha1 matches the live value,
  `003c72151e19f48a10d084c6c94efe019fd6795a` (108,550 bytes).
- **Inner pages (28–31)**: each file is the tree that was published, plus the
  element edits made afterwards (listed below). Services (29) and Contact (31)
  were also read back from the live site and spot-checked against these files.
- **Header (37) and footer (38)**: one link edit each, read back from the live
  site.
